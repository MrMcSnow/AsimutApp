# Security Policy

## Supported Versions

The following versions of **AsimutApp** are currently supported with security and maintenance updates.

| Version | Supported          |
| -------- | ------------------ |
| 1.3.x    | :white_check_mark: |
| < 1.2    | :x:                |

Older versions are no longer maintained. Please always update to the latest release to ensure compatibility and security.

---

## Reporting a Vulnerability

If you discover a security vulnerability within **AsimutApp**, please report it responsibly.

**How to report:**
- Send an email to **mr.mcsnow.skylight@gmail.com**  
- Optionally, you can also open a **private security advisory** via GitHub’s “Security” tab in this repository.

**Response time:**
- You will receive an acknowledgment within **48 hours**.  
- A full investigation and fix will usually be provided within **7–14 days**, depending on severity.

**Disclosure policy:**
- Please **do not** publicly disclose the vulnerability until it has been verified and patched.  
- Once resolved, contributors will be credited (if desired) in the release notes.

---

_Thank you for helping to keep AsimutApp secure for everyone._
